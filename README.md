# Viola Caipira

Base do app Expo/React Native alinhada aos docs e às imagens de referência.

Esta etapa cobre apenas a fundação do projeto:

- TypeScript estrito;
- aliases consistentes com `@/`;
- lint e testes mínimos;
- organização para os próximos passos da navegação, tema e telas.

## Estado atual

O shell de navegação e as telas ainda não foram criados nesta fase. Isso entra nas próximas tarefas do backlog.

## Comandos

- `npm run typecheck`
- `npm run lint`
- `npm run test`
- `npm start` quando o shell da app estiver pronto
